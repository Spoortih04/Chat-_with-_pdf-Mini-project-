This application enables users to interact with the content of a PDF file by leveraging Google's Gemini-Pro AI model, integrated within a Streamlit interface. The application begins by loading environment variables, particularly the API key required for authenticating requests to the Gemini-Pro model. It then configures the Streamlit page settings and defines functions for PDF text extraction using the PyMuPDF library (fitz). Upon uploading a PDF file, the application extracts its text and stores it. The user can then enter queries, which are combined with the extracted PDF text (if available) and sent to the Gemini-Pro model for generating responses. The conversation history is maintained throughout the session, and the responses are displayed in the chat interface. The application includes error handling mechanisms for cases where the API key is missing, the chat session fails to initialize, or there are issues in PDF text extraction or communication with the AI model.
